# 包封率数据采集规格

日期：2026-10-20
依据：`modeling/2026-10-19_smallmol-baseline/README.md`（第一轮粒径）与 `modeling/2026-10-20_ee-feasibility/README.md`（包封率可学性验证）
用途：指导自建实验数据的采集。这份规格只讲技术要求，不涉及对外叙事。

---

## 一、为什么是这个方案

两轮建模给出了三条可操作的依据：

**1. 目标变量换成包封率是对的。** 同一套评估代码、同一组种子、同样的判定标准下，四条诊断全部反转：

| 诊断 | 粒径 | 包封率 |
|---|---|---|
| 最好的模型打败常数基线 | 否（0/5 种子） | 是（5/5 种子，+4.99 个百分点） |
| 只用分子特征能否打败常数基线 | 否（0.257 vs 0.253） | 是（13.90 vs 18.40，5/5） |
| 去掉分子特征的影响 | 几乎没有（0.198 vs 0.192） | 明显变差（15.25 vs 13.41） |
| 结构相似性基线是否有用 | 比常数基线更差 | 比常数基线好 3.88 个百分点 |

**2. 真正的瓶颈是跨实验条件不可比，不是分子。** 包封率的信号在按分子分组时是 +4.99 个百分点，按论文分组时掉到 +0.01。相似性基线的方向甚至翻转（按分子分组好 3.88，按论文分组差 1.79）。原因是测定方法、N/P 比、缓冲体系、payload 在论文之间都不一样，同一个分子在两个实验室可以差 20 个百分点。

**所以这份规格的核心要求只有一条：把实验条件钉死，只让分子变。** 这是文献数据无论怎么堆都做不到的事，也是自建数据唯一真正的价值来源。

**3. 规模要求比第一轮估计的低。** 包封率的学习曲线显示 32 个分子就有 2.70 个百分点的效应，63 个到 3.86，之后基本走平。而且这条曲线是在含跨论文污染的数据上测的，单一实验室的条件下噪声更小，所需样本只会更少不会更多。

## 二、主实验设计

### 2.1 设计类型

**单因素设计：固定配方与工艺，只变化载药分子。**

| 变量 | 处理 |
|---|---|
| 载药分子 | **唯一的自变量**，40 到 60 个 |
| 脂质组成 | **固定一套**，所有样品完全相同 |
| 制备工艺 | **固定一套**，所有样品完全相同 |
| 载药比（药/脂质） | **固定**，按摩尔比或质量比固定，二选一并始终如一 |
| 包封率测定方法 | **固定一种** |

这个设计的全部意义在于：当工艺和配方都不变时，包封率的差异只能来自分子，分子效应因此可识别。第一轮失败的根本原因就是文献数据里做不到这一点（atenolol 和 propranolol 同配方不同工艺，粒径差 25 倍）。

### 2.2 固定下来的那套配方和工艺怎么选

建议直接选一套最接近未来产品形态的，并在方案里写死，之后不许改：

- 脂质组成固定为一个确定的四组分或三组分比例，记录到小数点后一位
- 制备方法固定（例如乙醇注入加挤出，或微流控），**所有可调参数都要写进方案并记录实测值**，不是写"按标准方法"
- 水相缓冲体系、pH、离子强度固定
- 载药比固定

**如果必须考察两套工艺，就把它当成第二个因素做完全交叉设计**（每个分子都在两套工艺下各做一次），绝对不能"一部分分子用工艺 A、另一部分用工艺 B"。后者会让工艺和分子再次混杂，这正是文献数据的病。

### 2.3 分子选择：铺开化学空间，不要在一个骨架附近密集采样

验证里一个必须正视的发现：没有任何模型显著打败「找最相似的分子抄答案」这个基线。这说明目前的信号形式是最近邻查表，不是可外推的构效关系。如果采样集中在少数骨架附近，新数据只会强化这个局面。

选择要求：

| 维度 | 要求 |
|---|---|
| 数量 | 40 到 60 个（下限 30，见第五节的分阶段方案） |
| Murcko 骨架 | **至少 15 个不同骨架**，每个骨架不超过总数的 20% |
| LogP | 覆盖 −1 到 6，每个整数区间至少 3 个分子 |
| TPSA | 覆盖 20 到 200 Å²，不要全部集中在一端 |
| 电荷状态 | 生理 pH 下的酸、碱、中性分子都要有，每类至少 8 个 |
| 分子量 | 200 到 900 Da |
| 必含 | **圣草酚**，以及 2 到 3 个结构相近的黄酮类（作为管线的直接锚点） |
| 建议含 | 3 到 5 个文献里已有可靠包封率的分子，用于与外部数据对齐和方法学校验 |

选分子时建议先用 RDKit 把候选集的描述符算出来，做一次最大化多样性的挑选（例如基于指纹的 MaxMin 选择），而不是凭手头有什么就测什么。这一步我可以直接出脚本。

### 2.4 每个分子做几个样品

- **每个分子至少 3 个独立制备批次**（不是同一批测三次）。独立批次才能估计真实的实验重复性。
- 每个批次的包封率测定做 2 到 3 个技术重复，取均值作为该批次的值。
- 分析单元 = 一个（分子 × 批次），所以 40 个分子对应约 120 个分析单元。

**为什么要独立批次**：模型的误差要和实验本身的重复性比较才有意义。如果批间标准差就有 8 个百分点，那么模型做到 10 个百分点的误差其实已经接近天花板。这个数现在我们不知道，必须测出来。

## 三、必须记录的字段

没有记录的变量就是不可控的混杂。下面每一列都要记，缺一列这批数据的价值就打折。

### 3.1 分子

| 字段 | 说明 |
|---|---|
| `compound_name` | 通用名 |
| `smiles` | **必填**，规范化后的 SMILES，用于算 InChIKey 和描述符 |
| `cas_number` | 可选，便于核对 |
| `purity_pct` | 供应商标称纯度 |
| `supplier`、`lot` | 批号，排查异常值时要用 |
| `stock_solvent` | 溶解母液用的溶剂（DMSO、乙醇等）与浓度 |

### 3.2 配方与工艺（即使全部固定也要逐条记录实测值）

| 字段 | 说明 |
|---|---|
| `lipid_1..4_name` / `_smiles` / `_mol_pct` | 四个脂质角色的名称、结构、摩尔百分比 |
| `drug_to_lipid_ratio` | 载药比，注明是摩尔比还是质量比 |
| `prep_method` | 制备方法 |
| `organic_phase`、`aqueous_phase` | 有机相和水相的组成、pH、离子强度 |
| `flow_rate_total`、`flow_rate_ratio` | 微流控时必填 |
| `extrusion_pore_nm`、`extrusion_passes` | 挤出时必填（第一轮发现膜孔径直接决定粒径，但文献里几乎不记录） |
| `temperature_c` | 制备温度 |
| `batch_id`、`prep_date`、`operator` | 批次溯源。**操作者也要记**，它是潜在的混杂源 |

### 3.3 测定结果

| 字段 | 说明 |
|---|---|
| `ee_pct` | **主目标**，包封率百分比 |
| `ee_method` | 测定方法，全程固定但仍要记 |
| `ee_free_drug_separation` | 游离药分离方式（透析、超滤、SEC、离心），不同方式结果不可比 |
| `drug_loading_pct` | 载药量，强烈建议一起测，它和包封率不是一回事 |
| `particle_size_nm`、`pdi`、`zeta_mv` | 一起测，用于质控和后续分析，**但不作为预测包封率的特征** |
| `recovery_pct` | 总药物回收率，低回收率的批次要标记 |
| `measured_date`、`instrument` | 溯源 |

### 3.4 质控标记

| 字段 | 说明 |
|---|---|
| `qc_flag` | 正常 / 可疑 / 排除 |
| `qc_reason` | 排除原因必须写明，**不许静默删除样本** |

## 四、数据表交付格式

一个 CSV 或 Excel，一行 = 一个分析单元（分子 × 批次），列名用上面的字段名。要求：

1. **单位统一**，写在列名里（`ee_pct` 而不是 `ee`）
2. **缺失值留空**，不要填 0，不要填 "N/A" 字符串
3. **不要把多个值塞进一个单元格**（"50:10:38.5:1.5" 这种要拆成四列）
4. 被排除的样品**保留在表里**并标记 `qc_flag`，不要删行
5. 每次交付附一个简短的变更记录（这一批测了什么、方案有没有变动）

拿到数据后我这边一条命令就能接进现有管线（`lnp/` 模块已经做成子集可配置的），评估协议直接沿用两轮已经冻结的那一套，保证新结果和已有结果可比。

## 五、分阶段执行

不建议一上来就做 60 个分子。先用小规模回答两个问题。

### 阶段一：方法学摸底（12 到 16 个分子，每个 3 批）

**目的不是建模，是测出三个数：**

1. **批间标准差**。同一个分子重复制备三次，包封率波动多少？这是模型误差的下限，没有这个数就无法判断模型做得好不好。
2. **分子间的真实差异幅度**。12 个分子的包封率跨度有多大？如果所有分子都在 85% 到 92% 之间，那么这个目标在我们的体系里方差太小，建模没有意义，需要换载药比或换体系把差异拉开。
3. **测定方法的稳健性**。同一个样品用两种游离药分离方式测，结果差多少？

分子选择上，这 12 到 16 个要**刻意选成化学性质差异最大的**（高低 LogP 各几个、酸碱中性各几个），这样最容易看出有没有分子效应。

**阶段一的验收标准**：批间标准差小于分子间标准差的一半。如果不满足，先改进工艺重复性，不要进入阶段二。

### 阶段二：主数据集（补到 40 到 60 个分子）

在阶段一确认方法学可靠之后，按第 2.3 节的多样性要求补齐。

**预期效果（基于包封率学习曲线的外推，标注为估计）**：在单一实验室固定条件下，30 个分子应该就能看出分子效应，40 到 60 个能让效应估计稳定下来。这个数比第一轮粒径估计的 40 到 100 个化合物要小，原因是去掉了跨实验室的噪声。

### 阶段三（可选）：工艺交叉

如果阶段二成功，再加一套工艺做完全交叉，这样可以同时估计分子效应、工艺效应和两者的交互。这是文献数据完全给不了的信息。

## 六、这批数据能回答什么，不能回答什么

**能回答：**

- 在我们自己的体系里，分子性质能不能预测包封率，效应有多大
- 圣草酚在这个体系里的包封率处在什么位置，哪些结构特征与它相关
- 实验的重复性是多少，模型误差的天花板在哪里
- 继续加分子的边际收益（可以直接画出我们自己的学习曲线）

**不能回答：**

- 跨到别的脂质体系或别的工艺还成不成立（阶段三才能回答）
- 体内行为。包封率是体外指标，和毛囊递送效率之间还有若干环节
- 不能用文献的包封率数据来扩充这批数据。这是本次验证最硬的结论：跨来源的包封率不可比，混在一起会把真实信号稀释掉

## 八、一句话总结

**固定工艺、铺开分子、每个分子三个独立批次、什么都记录。** 第一轮的失败和这一轮的限制都来自同一个原因：实验条件和分子混在一起变。自己做数据唯一不可替代的价值，就是把这件事做对。
