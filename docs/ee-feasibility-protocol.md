# 包封率可学性验证协议

状态：**已冻结**
冻结日期：2026-10-20（在跑任何模型之前）
性质：**可行性探针**，不是正式建模轮次。目的是用最小代价回答一个问题，不是拿一个好看的数字。

---

## 一、要回答的问题

第一轮（`modeling/2026-10-19_smallmol-baseline/`）的结论是：粒径主要由工艺决定，分子性质对它几乎没有贡献。由此提出的假设是「换一个在机制上更依赖分子性质的目标变量，任务可能就成立了」，首选包封率。

**本次验证只回答一件事：在有足够数据的地方，包封率这个目标是不是比粒径更可学？**

「更可学」的操作定义：在同一套评估标准下，模型能打败常数基线，而粒径那一轮没有做到。

## 二、范围说明（与第一轮任务范围的偏离，已获用户确认）

第一轮的任务范围明确禁止大分子建模。本次验证**只能**在大分子数据上做，因为小分子子集的包封率覆盖是 0 条（见 `docs/data-inventory.md` 3.4 节）。用户 2026-10-20 明确指示跑这个验证，范围变更是用户的决定，记录在此。

## 三、关键设计：这里"变化的分子"是脂质，不是载药物

包封率数据全部 563 条来自 LNP Atlas，payload 只有三类（mRNA 459、siRNA 93、DNA 11），没有结构，算不出描述符。

但**可离子化脂质有 197 个唯一结构、28 个唯一 Murcko 骨架**。所以本次验证问的是：

> 可离子化脂质的分子结构，能不能预测包封率？

这是第一轮那个问题的同构版本（"关键分子的结构能不能预测性能指标"），但换了一个分子角色。

**这个替换的代价必须写在结论里**：验证通过只能说明「分子结构 → 包封率」这类关系在 LNP 体系里原则上可学，**不能**直接推出「小分子药物的结构 → 它自己的包封率」也可学。后者仍需小分子的包封率数据来验证。本协议不允许把结论外推成后者。

## 四、分析单元与规模

去重键：`可离子化脂质 InChIKey` + 四类脂质占比 + `payload_type` + `paper_doi` + `prep_method_std`，目标取组内中位数。

**用 InChIKey 而不是脂质名字做键**：数据里 `ionizable_lipid_name` 只有 29 个取值，但对应 197 个不同结构，其中 `Custom lipid` 这一个名字下就有 170 个不同结构（文献里的脂质库筛选）。按名字去重会把 170 个不同的分子当成同一个。

规模（跑之前已确认）：

| 指标 | 数值 | 第一轮粒径作对比 |
|---|---|---|
| 分析单元 | **370** | 73 |
| 唯一分子（分组键） | **197** | 15 |
| 唯一 Murcko 骨架 | **28** | 15 |
| 论文 | 37 | 26 |
| 只有 1 个单元的分子 | 179 | 7 |

骨架数（28）明显少于分子数（197），所以**骨架划分在这一轮是一个真正的化学泛化测试**，不像第一轮那样与化合物划分等价。

## 五、目标变量与指标

目标：`encapsulation_efficiency_pct`，取值 0 到 100.3（2 条略超 100，是四舍五入，保留不改）。

**不做变换。** 粒径那一轮取了 log10 是因为分布跨三个数量级且右偏；包封率是有界百分比，直接用原始值，误差单位就是百分点，便于直接读。

| 指标 | 角色 |
|---|---|
| **MAE（百分点）** | **主指标** |
| RMSE（百分点） | 辅助，看误差是否集中在少数样本 |
| R²（合并 out-of-fold 算一个） | 辅助，与常数基线的关系一目了然 |
| Spearman ρ | 辅助，只看排序 |

**判定标准与第一轮完全一致**：模型与基线的配对 ΔMAE 的 95% cluster bootstrap 区间（按分子重抽样，2000 次）是否跨过 0，且 5 个种子的符号是否一致。不看单个指标的绝对值。

## 六、划分方式

| 代号 | 分组键 | 说明 |
|---|---|---|
| **G1（主）** | 可离子化脂质 InChIKey | 197 个分组，5 折 |
| **G2** | 可离子化脂质的 Murcko 骨架 | 28 个分组，5 折。真正的化学泛化测试 |
| **G3** | `paper_doi` | 37 个分组，5 折。与第一轮的 S3 同口径，用来量化论文混杂 |

同一分子（或骨架、或论文）的记录绝对不能同时出现在训练集和测试集。

## 七、基线与模型

与第一轮完全相同的四个基线：

- **B0 常数基线**：永远预测训练折的均值
- **B1 相似性基线**：按可离子化脂质的 Morgan 指纹（radius=2，2048 位）找训练折里 Tanimoto 最相似的分子，用它的包封率中位数
- **B2 诊断（无分子特征）**：只用配方组成、payload 类型、工艺
- **B3 诊断（只有分子特征）**：只用可离子化脂质的描述符和指纹

模型顺序与超参数网格与第一轮一致（协议第八节）：Ridge → 随机森林 → 梯度提升树，嵌套交叉验证调参，内层按同一分组键的 3 折，只用训练折。

种子固定 0 到 4，全部报告，不许只报最好的。

## 八、特征

| 分块 | 内容 |
|---|---|
| M-desc | 可离子化脂质的 12 个 RDKit 描述符（与第一轮同一组） |
| M-fp | 可离子化脂质 Morgan 指纹 2048 位，折内频率过滤 + 折内筛选，k ∈ {0, 32, 128} |
| F-comp | 四类脂质摩尔占比 + payload 类型 one-hot（3 类，每类样本都很多，不是论文代理变量） |
| P | `prep_method_std`、`flow_ratio_imbalance`、`total_flow_rate_ml_min_std`、`process_temp_c_std` |

禁止字段沿用第一轮清单，另加：`particle_size_nm` 和 `pdi` 不作为特征（它们是同一批实验的其它测量结果，用它们预测包封率会让结论无法解释成「从分子和配方预测」）。

缺失值处理与第一轮一致：组分不存在填 0 并给 `has_*` 标记，真缺失保留 NaN 加缺失指示列，填充只在训练折内做。

## 九、成功标准（事先写死）

| 结论 | 条件 | 后续动作 |
|---|---|---|
| **可学** | 最好的模型在 G1 下打败 B0（配对 ΔMAE 的 95% CI 不跨 0 且 5 个种子符号一致），且 B3（只用分子特征）明显好于 B0 | 换目标是对的。出小分子包封率的数据采集规格 |
| **部分可学** | 在 G1 下打败 B0，但 B3 不比 B0 好，或 G2 骨架划分下优势消失 | 信号存在但主要来自配方和工艺，不是分子。需要在数据规格里专门设计可识别性 |
| **不可学** | 没打败 B0 | 问题比目标变量更深，整个任务定义要重想。不要去采包封率数据 |

**无论结果如何，都要报告 G1 与 G3 的差距**（论文混杂程度），以及 B2 与 B3 的对比（分子贡献 vs 配方工艺贡献）。这两项是本次验证真正要买的信息。
