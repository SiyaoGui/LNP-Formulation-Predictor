## 二、需要数据工程助手注意的事项

1. 块 528 至 530 构成「屏障分子机制」三连，新增率 100% / 95% / 90%，是扩充期开启的最高产方向之一。此前的检索集中在「药物怎么过屏障」，这三块转到「屏障本身由什么决定」，与已有行几乎不重叠，说明分子机制层面仍有大量未覆盖文献。基底膜（块 532，95%）与神经血管单元（块 531，50%）同属该族，前者未饱和，后者已部分被早期块覆盖。

2. 块 528 的检索返回中出现大量肠道上皮紧密连接文献（首条即为肠上皮），而非脑内皮。claudin/occludin 的调控机制在两种上皮间高度同源，文献互相引用，但定量参数（TEER、Papp）不可跨组织通用。建议数据工程阶段对这批行加「组织来源」标记，区分 脑内皮／肠上皮／肾上皮／血视网膜屏障，不要把肠道 TEER 当作脑屏障基线。

3. 块 529 涉及 Mfsd2a 介导的脂质转运抑制小窝转胞吞这一机制：脑内皮的低转胞吞率不是被动缺失，而是由 Mfsd2a 的脂质组成主动抑制。这与本项目 LNP 方向直接冲突——若递送载体本身改变内皮膜脂质组成，可能在增强摄取的同时破坏屏障选择性。该冲突登记在此，不新增待决策项。

4. 块 531 中 Armulik 2010 与 Daneman 2010 两篇 Nature 对周细胞覆盖率与通透性的定量关系给出了可用数值，但摘要只给相对描述，已标需全文。块 531 还出现一条与常识相反的结论：在 0.1% 氧的重度缺氧下周细胞比星形胶质细胞更能维持屏障功能，而在 1% 氧下周细胞反而加速屏障破坏，方向随缺氧程度翻转。做缺氧相关特征时不能用单一方向的符号。

5. 块 532 的基底膜层粘连蛋白亚型存在物种与模型间的系统性分歧：人 BMEC 转录组提示主要为 Laminin 321，小鼠转录组与人／鼠蛋白组提示 Laminin 521，iPSC 来源 iBMEC 提示 Laminin 511。三者互不一致。这是模型来源分层变量的又一例证（此前已在 iPSC-BMEC 是否为真内皮一事上登记过）。

6. 块 533 的 P-gp 诱导通路（谷氨酸 → NMDA 受体 → cPLA2 → COX-2 → mPGES-1 → PGE2 → EP1）是一条完整的可干预链条，各环节均有对应抑制剂文献。其定量结果散落在多篇中，海马 P-gp 上调 92% 至 197%、[11C]metoclopramide PET 中 k2 上升 21% 至 34% 等数值已入表。注意 P-gp 在不同疾病中方向相反：癫痫与卒中中上调，衰老与阿尔茨海默病中下调。做疾病状态特征时须按疾病分别赋号，不能合并为「疾病」一个二值变量。

7. 块 525 与 531 新增率均为 50%，是本组最低的两块，接近饱和但尚未到零。块 533 为 72.2%，仍有空间。
