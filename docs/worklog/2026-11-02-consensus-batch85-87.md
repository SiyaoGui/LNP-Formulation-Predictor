## 二、需要数据工程助手注意的事项

1. 块 486 在批 86 中出现块序乱序：三次并行检索返回顺序与发出顺序不一致（发出为 MDCK 外排、图神经网络、环肽，返回为 MDCK 外排、环肽、图神经网络），经 dump3 首标题核对后纠正再写入。本月已多次出现同类情况，核对步骤不可省略。
2. 块 498「GLUT1 与 MCT1」新增率 89.5%，是载体介导入脑方向中覆盖最薄的一块。GLUT1 与 MCT1 是血脑屏障上两条已确证的营养物质载体通路，与块 497（LAT1）同属「可被前药利用的内源性载体」类别，三者合并构成载体介导递送的完整底物面。
3. 块 497「LAT1」新增率仅 22.2%，该方向此前已被多个块覆盖（转运体定量蛋白质组学、载体介导入脑等），判定接近饱和。块 496「前药策略」30%、块 491「对流增强递送」30% 同属接近饱和。
4. 块 492「血浆蛋白结合」提供的是 Kp,uu 计算链条上的关键一环：脑组织与血浆游离分数的测定方法及其误差来源。该块中多条来源明确指出一个与建模直接相关的结论：血浆蛋白结合与组织结合不应作为独立优化目标，因为降低结合率不必然提高体内游离浓度。若后续把 fu,plasma 或 fu,brain 作为可优化的配方参数纳入模型，这一点需要先确认。相关记录已登记，不新增待决策事项。
5. 块 490 的记录显示纳米粒在脑实质内被小胶质细胞与星形胶质细胞优先摄取，且摄取倾向随表面修饰（羧基与羟基封端、聚合物种类）而变。这是「入脑之后到哪里去」的数据，与「能否入脑」是两个不同的终点，建议在表中分列。
