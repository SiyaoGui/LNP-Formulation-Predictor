## 三件实质工作

### 一、许可字段全部实查

用 Crossref API 批量查了全部 469 个 DOI，467 个解析成功。
许可列从"未核实"换成了实查值：CC 系列 244、仅出版商或 TDM 条款 185、未列或待核实 40。

这件事的价值不在于把一列填满，而在于**推出了一个可直接行动的数字**：
152 篇需全文的论文里有 **82 篇是开放许可**，不需要订阅就能合法下载。
获取清单已按"脑递送优先、P0 优先、开放许可优先"排好序。

### 二、LNPDB 的定位被修正

第 3 批把 LNPDB（19528 条）列为开放数据集第一名、P0、"第一个去抽取"，
并留了一句"小分子载荷占比未知，需要核实"。

本批用 PubMed 取回该文标题与摘要原文核实，结论明确：
**标题本身就是 "...for nucleic acid delivery"**，摘要全文未出现小分子字样。
所以对一个小分子载荷的项目，这 19528 条不能当训练集。
仍然有用的是三项载荷无关的东西：脂质组成与实验方法的标准化编码方案、
自动生成的 CHARMM 力场文件、以及可引用于申请书背景的作者原话。
优先级已从 P0 下调为 P1，`docs/open-datasets.md` 与主表都已改。

精确占比仍需进站看，但 `lnpdb.molcube.com` 被本环境网络策略拒绝，已列入待办。
