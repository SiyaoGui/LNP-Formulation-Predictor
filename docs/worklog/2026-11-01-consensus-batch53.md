## 3. 主要发现（仅引用 Consensus 返回的摘要）

### 3.1 块 395：RPN 的方法学局限，直接关系冻结决定 1

冻结决定 1 把理化 CQA 按 RPN 排序。本块文献显示 RPN 本身有大量被记录的方法学问题：

| 来源 | 来源类型 | 内容 |
| --- | --- | --- |
| Borchert 2019 Bioengineering（生物药） | 同行评议 | RPN 是严重度、发生度、可检测度三个有序量表值的乘积，乘有序量表值和等权假设可能造成误判；作者给出定量算法，显示严重度和发生度对工艺参数关键性的贡献不同，并展示用 RPN 误判的风险 |
| Kim 2017 RESS | 同行评议 | 三个因子在文献中定义定性、含义冲突，没有底层模型；因子之间的关系未知 |
| Chang 2014 | 同行评议 | RPN 范围 1 至 1000；重复数值多、违反量表假设、未考虑 S、O、D 权重 |
| Chang 2013 | 同行评议 | 同样列出四点缺陷：重复率高、假设三因子等权、不满足有序加权规则、未考虑失效模式与原因间的关系 |
| Kim 2024 JACMP（放疗质控） | 同行评议 | 用同一失效模式被两次质控检出的记录，经验性估计发生度和可检测度，可用于验证专家共识值 |
| Jo 2026 BJOPM（药品 GMP） | 同行评议 | AHP-FCE 模型相对传统 FMEA 把关键风险上调（Wilcoxon p = 0.0043）；批次失败率阿苯达唑从 2.8% 降到 1.1%（n = 254），四环素从 2.7% 降到 1.4%（n = 426）。局限：单一场地、前后对比、没有随机和同期对照、两条产品线、依赖专家打分 |
| Bhattacharjee 2020 Safety Science | 同行评议 | 用 logistic 回归替代乘积形式，正确分类率 77.47%，ROC 准确率 81.98%，截断值 0.56；对象是电厂水泵，不是药品 |
| Barends 2012（分析验证） | 同行评议 | 用相对频率替代分类打分的发生度和可检测度 |

其余多篇（模糊 FMEA、熵加权、ELECTRE TRI、灰色关联、DEMATEL 等）摘要为方法描述，没有性能数值，已标需全文。

含义：这些是通用工程和少量药品文献，没有任何一篇针对纳米药物 CQA。结论只限于方法层面：RPN 排序对打分方式、等权假设和量表选择敏感。Efremova 2026（已在主表）给出的 mRNA-LNP RPN 值（EE 100、粒径 80、PDI 64 等）也依赖专家打分。

来源可信度：10.5281/zenodo.1332907 来自 WASET 类来源，层级较低，只作候选，不采用为证据。

### 3.2 块 393：监管框架

### 3.3 块 394：阿霉素脂质体仿制药

| 来源 | 来源类型 | 内容 |
| --- | --- | --- |
| Maiti 2017（已在主表） | 同行评议 | FDA 与 EMA 对仿制脂质体阿霉素的指南要求 30 多项理化参数相似 |
| Bhowmik 2018 / Li 2022（已在主表） | 同行评议 | 人体生物等效性试验：90% 置信区间落在 80% 至 125%；Li 2022 为 44 例入组分析 |
| Jayaraj 2023（本批新增） | 同行评议 | 毛细管电泳释放法，pH 6.50、47.0 °C 下 7 小时内释放 100%；5 种制剂（含参比）在该条件下释放曲线相近 |
| Yurtsever 2023（本批新增） | 同行评议 | 电化学释放法：37 °C 下 pH 从 5.5 升到 7.4，释放从 7% 增至 40%；pH 6.5、52 °C 下 3 小时内超过 80% |
| Ahmadvand 2016 / Lipsa 2023（已在主表） | 同行评议 | 不同批次与不同仿制品之间存在细微理化差异，并带来补体与细胞因子响应差异 |

含义：阿霉素脂质体是一个有完整监管等效体系、30 多项参数相似性要求的成熟案例，可作为「CQA 清单」的外部参照，但它是脂质体而不是可电离脂质 LNP 小分子载荷。
