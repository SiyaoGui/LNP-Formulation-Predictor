## 二、需要数据工程助手注意的事项

1. 块 480「室周器官」新增率 100%，是本月迄今第四个零重叠的块。室周器官（穹窿下器、最后区、终板血管器、正中隆起、神经垂体）属于生理性无屏障区，其通透性数据不能与完整屏障数据混用，和块 425、451、453、460、461 一样需要「屏障状态」字段区分；该字段建议取值仍为：完整／病理受损／肿瘤破坏／物理开放（聚焦超声、甘露醇）／生理无屏障（室周器官）／绕过（鼻脑、鞘内、CED）。本组又新增两类需要分列的情况：块 475 的鞘内与脑室内给药属「绕过」，块 478 的脉络丛属独立的血脑脊液屏障界面，与血脑屏障并列而非从属。
2. 块 478 的检索结果中多条来源明确指出一条与本项目直接相关的方法学结论：脑脊液药物浓度不是血脑屏障转运的指标，脑脊液给药的药物主要经体积流快速回血、向脑实质渗透受扩散限制。若数据工程阶段把脑脊液浓度数据与脑实质浓度数据合并建模，会引入系统性偏差，建议在表中分列「测定基质」（血浆／脑脊液／脑组织匀浆／脑间质液／细胞内）。
3. 块 477「性别差异」新增率 95%，是一个完全未被此前任何块覆盖的协变量方向。该块的记录大多涉及转运体表达与脑暴露的性别差异，若后续建模使用动物数据，性别是一个未登记的分层变量。
4. 块 474「核受体 PXR 与 CAR 对屏障 P-gp 的诱导调控」新增率 85%，提供的是屏障外排能力的可调控性证据，与此前块 465、466、467 的转运体静态定量数据互补，属机制链条上游。
5. needs_fulltext 仍由正则机械判定，本组未做人工校对。按扩张期规则 3 保持原样。已知误判模式不变：漏判「X 倍」「X-fold」表述，误捕粒径、缓冲液浓度、组分百分比、主成分方差等非终点数字。块 479、480 的通量与通透性数据多以科学计数法表示（如 1.55e-5 cm/s），正则对这类写法的捕获情况未经验证。
