## 3. 主要发现（仅引用 Consensus 返回的摘要）

### 3.1 块 397：专家打分的主观性与一致性（通用工程文献，不是药品）

| 来源 | 来源类型 | 结果 |
| --- | --- | --- |
| Akdamar 2026 Ocean Engineering | 同行评议 | 海洋燃气轮机 48 个失效模式、10 位专家。聚合方法（中位数、平均数）的选择会改变排序：新排序与传统均值 RPN 的 Spearman ρ = 0.9451，但个别失效模式的位次最多变动 11 位 |
| Subriadi 2020 Heliyon（IT 风险） | 同行评议 | 两个团队对同一案例做传统 FMEA，一致性相关 0.848，改进后 0.937；极高风险项数量在传统方法下差 4 项，改进后相同。局限：两轮由同一团队做，存在记忆影响 |
| Montero-Díaz 2026（PET 放射药物中心 HVAC） | 同行评议 | 10 位专家评 15 个失效模式，1 至 10 分制；RPN 与 O、S 强相关，RPN 不小于 150 为关键 |
| Bozkuş 2025（汽车厂） | 同行评议 | 严重度和发生度权重最高（0.4062 与 0.2589），使用模糊 Cohen's κ 检验专家共识 |
| Testik 2022（检测与校准实验室） | 同行评议 | 199 个失效来自 91 次检查；传统 FMEA 与模糊 FMEA 的优先序高度重合 |

含义：同一风险清单，换聚合方法或换团队，排序会明显移动；极高风险项的数量也可能不同。这是通用工程证据，不针对纳米药物 CQA。其余 14 条为模糊集、证据理论、社会网络共识等方法论文，摘要无性能数值。

### 3.3 块 398：数据驱动的定量风险排序

| 来源 | 来源类型 | 结果 |
| --- | --- | --- |
| Taylor 2021 Bioengineering（单抗工艺） | 同行评议 | 蒙特卡洛敏感性分析自动确定严重度排序，可把工艺表征中需研究的参数最多减少 24% |
| Stocker 2014 Int J Pharm（片剂包衣） | 同行评议 | 用计算机模拟生成定量知识做 FMEA，以包衣质量均一性的变异系数作为定量再评估依据 |
| Borchert 2019（批 53 已列） | 同行评议 | 量化 CPP 评估，对比 RPN 显示误判风险 |
| Berardi 2026 JPS | 同行评议 | 原料变更的 CMA 与 CQA 框架：风险不是原料的固有属性，而来自它与具体配方与工艺体系的交互；摘要无数值 |
| Alt 2016（单抗 CQA） | 同行评议 | 系统的科学风险排序与过滤方法确定 CQA，摘要无数值 |
