第二和第四个数字要说明口径，否则会被误读成「这篇没有载荷」：

- ACBI2 是一个真实载荷，但**原文没有给结构式**。没有 SMILES 就算不出 InChIKey，
  也就无法和现有 22 个化合物做跨论文去重，更无法参与按化合物分组的建模。
- 所以它在「唯一化合物」这个瓶颈指标上的贡献确实是 0，不是统计口径的问题。
- 另外 ACBI2 分子量 1064 Da，超过协议的 900 Da 上限，45 条全部标
  `mw_over_default_cap = TRUE`，默认不进主数据集。

`scripts/report_compound_gain.py` 现在两个口径都报，并点明哪些载荷缺结构。

## 核对过的事

抽取不是只跑通脚本就算完，这几项是逐条对过原文的：

1. **DoE 行对齐**。抽样核对 run 1/2/3/4/38/39/40 的 6 个因子与 5 个响应，
   与 docx 表 8、表 9 逐个数字一致。
2. **确认实验的组分**。正文表 3 给的是 `DOPC/DOPG/Chol/PEG` 四元组。
   第 7 页正文另有一段**独立的文字描述**把 5 个配方各自写了一遍
   （formulation 1: 47.5/47.5/5；2: 50.6/42/2.4/5；3: 37.7/50/7.3/5；
   4: 46.9/41.3/11.8；5: 61.5/37/1.5）。两处来源互相印证，5 个全部吻合。
3. **确认实验取哪一列**。表 3 每个响应给三个数，表头是
   `95% prediction interval low | Data Mean | high`。取中间的实测均值。
   这一点必须查表头：三个数里中间那个并不总在中间大小位置
   （如配方 1 的粒径是 65.1 / 95.9 / 96.0），靠数值排序会取错。
4. **组分加总**。45 条全部加总到 100.0，0 条异常，没有做过重新归一化。

## 一处收集阶段的判断错误，已改

可行性探查时根据摘要 "demonstrated across three distinct PROTACs" 把本文标为
「P 类（3 个 PROTAC）+ L 类」。核对全文后这是错的：

- ACBI1、ACBI3 只出现在 HPLC 方法验证的文字里（各 6 次提及），没有任何配方数据
- ACBI2 提及 84 次，是唯一有配方与响应的载荷
- 那句话说的是 HPLC 方法对三个 PROTAC 都适用

本文是纯 L 类。`docs/feasibility-probe.csv` 里该行的 `block_class` 需要从
`both` 改成 `L`。这正是协议里「不许把摘要里的描述当作定量数据」要防的情况，
而我在收集阶段仍然踩了一次。

## 一处 schema 不够用的地方

仓库只有 4 个脂质槽位（ionizable / helper / sterol / peg），DOPG 没有对应槽位。
按槽位硬塞只能把 DOPC 和 DOPG 一起放进 helper 槽。但 DOPG 是阴离子脂质，是本文
zeta 电位的主要驱动：

- 阴离子份额与 zeta 的 Pearson r = **-0.645**
- DOPG = 0 的 19 条，zeta 中位 **-2.2 mV**
- DOPG > 0 的 26 条，zeta 中位 **-16.3 mV**

折叠进 helper 槽后 `helper_lipid_pct` 看不出这个差别。所以除了
`composition_raw_verbatim` 留原文四元组，另立三列：
`component_dopc_pct`、`component_dopg_pct`、`anionic_lipid_frac_of_total`。

这不是本文特有的问题。阴离子脂质（DOPG、DOPS、DSPG）在脂质体文献里很常见，
4 槽位 schema 遇到它们都会糊掉。`docs/literature-protocol.md` 的 schema 已冻结，
不在本次改动；记在这里，等后续批量抽取时一并评估是否要加
`anionic_lipid_*` 一组槽位。

## 没抽的

- HPLC 方法与原始测定值表：对建模无用
- 表 3 两侧的 95% 预测区间：那是模型产物，不是实测离散度。原文**没有**报
  三次重复的标准差，所以 `value_sd` 留空，不拿预测区间顶替
- 40 个 DoE run 的重复次数：原文未报，`n_replicates` 留空
  （确认实验的 `n_replicates = 3` 有原文依据）
- `linked-discoveries-42598203-50rows-2026-10-28.csv`：这不是本文的补充材料，
  是以本文 PMID 42598203 为中心的 PubMed 引文网络导出（50 行）。
  不是定量数据，本次不抽；留着将来做引文溯源

## 这批数据能干什么

它不抬高唯一化合物数，所以对「跨化合物泛化」这个主问题没有帮助。
但它是目前三个数据集里**唯一一个组分比例连续变化、响应完整、且全部出自同一
实验室同一方法同一台仪器**的区组。45 条、6 个因子、5 个响应全齐。

所以它适合单独检验一个弱得多但可能真能成立的问题：**固定载荷下，脂质组分比例
能否预测 EE**。这和仓库里已冻结的那个结论（跨源 EE 不可比）不冲突，因为它整个
区组内部不跨源。这件事等用户确认后在特征对比实验里做，本次不做。
