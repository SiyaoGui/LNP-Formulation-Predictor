## 三、成品表字段字典 `docs/master-candidates.csv`

11 列，UTF-8，标准 CSV（字段内有逗号和换行，**务必用 `csv` 模块读，不要用
`wc -l` 数行**——`why_matters` 里有嵌入换行，`wc -l` 会多数）。

| 列 | 类型 | 含义与约定 |
|---|---|---|
| `doi` | 字符串 | 主键。全表零重复（`dedupe.py` 保证）。去空格、去尾点、小写化后比较。 |
| `title` | 字符串 | 论文标题。双引号已替换为单引号避免 CSV 转义问题。 |
| `year` | 字符串 | 发表年；`"0"` 表示元数据缺年。 |
| `journal` | 字符串 | 期刊名（取自 Consensus 返回的 meta）。 |
| `workflows` | 分号分隔码 | 该论文服务于哪些建模工作流，见下方代码表。一篇可多码。 |
| `source_type` | 枚举 | `peer_reviewed` / `preprint` / `unknown`。preprint 按期刊名正则判定（bioRxiv/medRxiv/…）。 |
| `license_status` | 字符串 | 开放许可状态，来自 Crossref。**当前 4173 行为空**（见第六节坑 1）。 |
| `in_zotero` | 枚举 | 是否已导入 Zotero。**当前全为 `N`**——一篇都还没导。 |
| `priority` | 枚举 | `P0` / `P1` / `P2`，检索时按主题重要性人工指定。当前 P0 6445 / P1 2915 / P2 104。 |
| `needs_fulltext` | 枚举 | `Y` = 摘要无定量结果需读全文；`N` = 摘要已有定量片段。**正则机械判定，非人工审**（见坑 2）。 |
| `why_matters` | 字符串 | 中文主题前缀 + `；摘要数据：` + 最多 3 条定量片段（粒径/包封率/电位/DTE/R² 等），或 `；摘要无定量结果，需全文`。主题前缀是检索块主题的人读版。 |

## 六、数据质量警告（务必先读）

1. **license 字段 4173 行为空**。批 50/55 的 Crossref 跑之后新增的约 4000 行没覆盖。
   刷新不花 Consensus 额度：填 `pipeline/crossref.py` 的 `mailto` 邮箱 →
   `python3 crossref.py` → `python3 fill_license.py`。这是**入口任务，建议先做**。
2. **`needs_fulltext` 是正则机械判定，不是人工审**。逻辑：摘要里正则命中粒径/包封率/
   电位/DTE/R²/剂量/PDI/百分比等片段就判 `N`，否则 `Y`。会有假阴假阳。按用户的
   扩容期规则这些不逐条人工核；你若要用它当筛选门槛，先抽样核准确率。
3. **`in_zotero` 全为 N**：一篇都没进 Zotero。`docs/fulltext-acquisition-list.md` 和
   `docs/doi-list-fulltext-priority.txt` 列了优先导入清单（含约 82 篇开放许可可直接合法下载）。
4. **`wc -l` 不可靠**：`why_matters` 含嵌入换行，数行必须用 Python `csv` 模块。
5. **preprint 判定靠期刊名正则**，少数预印本若期刊名不规范会漏判为 peer_reviewed。
6. 成品表的 `why_matters` 定量片段是**摘要里的字符串**，不是结构化数值，没做单位
   归一，也没区分这数字描述的是哪个变量。要做定量建模得再解析一层。

## 八、跨工作记录沉淀的建模约束（本月最有价值的产出，别漏）

本月 10 篇工作记录（`docs/worklog/2026-11-*batch1{36..62}*.md`）登记了数百条给数据工程
助手的注意事项和矛盾。**这些不是文献摘要，是直接约束你怎么建特征和划分的判断。**
最该先看的横切规律（每条都在多批次独立出现，已到可当硬约束的程度）：

1. **摄取量 ≠ 功能性递送**（证据最密集）：核内累积高而活性为零、细胞内总累积与敲低
   不相关、蛋白冠提高摄取反降表达。→ 不能把「摄取/累积」当功能性递送的代理特征。
2. **相似理化参数不同功能**（至少 7 个反例）：5A2-SC8 vs 3A5-SC14（pKa 粒径都同、只一个
   能功能递送）、两组 ALC-0315 载荷拷贝数相近而编辑效率差 1.5 倍、种子区全局热力学去
   稳定相同而大鼠安全性差异显著……→ 理化参数不足以预测功能，化学结构/内部结构也要进特征。
3. **受体内化速率 > 受体丰度**（3 次独立确证：六受体系统比较、AOC、T 细胞靶向）。
4. **体外不预测体内**（281 个配方高通量直接确证；按论文/研究分组后优势归零——这也是
   三轮建模的核心教训，见 `docs/handoff.md`）。
5. **种属外推按终点分项，不按物种**：GalNAc-ASO 代谢物谱可外推、微针免疫应答不可外推、
   补体与血小板效应被 NHP 过度预测。→ 「可外推/不可外推」不能打在物种上。
6. **同一参数最优值依给药部位而变**：价数四价在视网膜最优、三价滞留注射部位、二价入肝、
   单价入肾。→ 带部位的交互项。
7. **同一靶点同一位点在 ASO 与 siRNA 两种模态下毒性完全不同**。→ 模态是毒性特征。
8. **器官水平敲低系统性低估细胞水平敲低**（40% vs >70%）。→ 分辨率决定结论。
9. **PEG、载体与载荷、条码类型等的方向会随上下文反转**（PEG 在系统给药有益、吸入有害；
   同一 repRNA 用 LION 成功、用 LNP 失败）。→ 必须建交互项，不能用主效应。

每条的完整出处、论文和数字在对应 worklog 的「三、需要数据工程助手注意的事项」和
「四、矛盾与冲突登记」两节。
