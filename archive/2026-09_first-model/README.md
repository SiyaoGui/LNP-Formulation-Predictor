# First model, September 2026

The first particle-size model (stages M1 to M6) and everything it produced. It was replaced by the evaluation work in `modeling/` and `docs/`, and is kept so the history can be traced.

| Folder | Contents |
|---|---|
| `code/` | Data merging, feature engineering, training, SHAP analysis and the process-parameter fixes |
| `data/` | The first merged table, feature matrices and candidate formulations from patents and preprints |
| `results/` | Cross-validation results, the trained model and SHAP outputs |
| `docs/` | Stage notes M1 to M6, data dictionaries, planning notes and the patent and preprint research (Chinese) |

The scripts were written for the old flat layout, so file paths in them need adjusting before they run.
