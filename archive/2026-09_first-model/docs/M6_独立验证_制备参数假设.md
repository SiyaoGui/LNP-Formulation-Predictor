# M6：制备参数假设获得独立专家验证（2026-09-15）

## 背景

M6的Fix A/B/C给模型加了一组制备参数特征（flow_ratio_imbalance、total_flow_rate_ml_min_std、prep_method_std、device_or_chip_std、measurement_instrument_std），当时是基于"不同文献用不同制备方法，可能是跨数据集误差的一个来源"这个假设做的。加了之后R²没有变好，是-0.135，当时如实报告为已知成本，不是bug。

## 新证据

2026-09-15和哥本哈根大学（KU）的Camilla Foged教授（疫苗设计与递送方向）见面。她在完全不知道M6已经做了这组特征工程的情况下，主动、独立地指出粒径不只取决于组分配比，还取决于制备方法，具体是微流控混合时的总流速和两相流速比，和已经在用的特征几乎一一对应。她组内的Federica Sebastiani后来又单独重申了一次同一个点。

这不能证明这组特征一定能提升模型表现，工程方向对不等于统计结果会变好，之前的负结果仍然成立。但说明特征选择的方向本身站得住脚，问题更可能出在数据量或数据质量，不是特征思路本身错了。

## 新的候选数据来源

一篇bioRxiv预印本（Camilla推荐，具体条目待核实，需要Siyao提供准确URL），系统对比了手动混合、微流控(Ignite)、湍流混合(CIJ/Helix/MIVM等)几种制备方式，同一组分下变换总流速比和乙醇去除方式，记录了size/PDI/EE的变化。这正是M6目前缺的"同组分、变制备参数"的对照数据类型，如果能拿到原始数值而不只是文字结论，价值可能高于普通的跨文献拼接数据。已抓取到的结论摘要：

- 手动混合：PDI最低，EE最高（透析前92.34%，透析后89.74%）
- 水相比有机相流速比3:1 vs 1:1：3:1做出的颗粒更小（手动混合除外），EE前者普遍超过80%，后者普遍不到80%
- 透析去乙醇：显著改变脂质相态（从Lα/HII混合相变成以Lα为主），粒径普遍变大（手动混合、部分MIVM配置例外）

另有Camilla自己组的论文（Lokras et al., *Advanced Functional Materials* 35(51), 2025, DOI: 10.1002/adfm.202505627, CC BY开放获取），补充材料据其口头描述含weight ratio/ionizable-to-PEG ratio/lipid composition/size/PDI/EE的完整表格，但该论文制备方法固定不变，只能用于学习组分和性质的关系，学不到制备参数本身的影响。全文抓取被Wiley反爬虫挡了两次（403），需要Siyao本人下载PDF后提供。
