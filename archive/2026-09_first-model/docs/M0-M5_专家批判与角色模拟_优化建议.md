# 严苛视角批判 + 三方角色模拟：M0–M5 优化建议

本文档面向 Track A（全身给药 LNP/脂质体配方可行性预测平台）目前完成的 M0–M5 全部产出，做两件事：（一）以严苛的药物递送领域专家视角列出结构性漏洞；（二）分别模拟学术界、商业/大药企、工业制造三方角色，各自从自己的立场审视这个平台。最后综合成 M0–M5 的具体优化建议。

---

## 一、领域专家视角：结构性漏洞清单

### 已有问题重申（申请材料里已交代过，这里只标结论，不重复论证）

1. **场景错配**：M0–M5 全部训练数据（LNP Atlas、Luciani、PMC_IVR）都是全身性/肠外给药场景，没有一条透皮/毛囊渗透数据。M4 模型回答的是"能不能形成正常尺寸颗粒"，回答不了"这个颗粒能不能穿过角质层、富集在毛囊"。
2. **圣草酚证据本身的缺口**：圣草酚单体逆转白发缺乏直接证据，现有证据链是相关黄酮 sterubin/圣草提取物（详见项目记忆 eriodictyol-evidence-gap）。这个缺口独立于递送平台是否扎实。
3. **"Custom lipid" 37% 天花板**：LNP Atlas 里超三分之一的电离脂质记录追溯不到具体结构，任何基于这批数据训练的模型，可解释性和可迁移性都有硬上限。
4. **监管定性风险**：圣草酚+脂质递送系统用于头皮，存在被欧盟/NMPA 认定为"疑似药品"而非化妆品的边界风险。

### 本次新发现的问题

**① 单一终点建模，掩盖了"配方成功"的真实定义。** M4 只对 `particle_size_nm` 建了模型，没有联合建模 PDI、包封率、zeta 电位，更没有涉及任何稳定性数据（储存条件、冻融、血清/介质稳定性）。真实的制剂科学家评估一个配方，看的是五到十个 CQA 同时达标，不是单一粒径数字达标。这不是"下一步该做的事"这么简单——现在 R²=0.43 这个数字的说服力被结构性高估了：一个粒径预测尚可、但包封率/稳定性完全没建模的工具，在真实决策场景里价值有限。

**② 组成和工艺高度混淆，模型可能学到的是"哪篇论文"而不是"哪种化学"。** 三个数据源里只有 Luciani 把微流控工艺参数（流速比、总流速）结构化进了字段；LNP_Atlas 的 `synthesis_info` 是完全没解析的文本，PMC_IVR 的制备方法也是文本，M3/M4 特征矩阵里都没有把它们纳入结构化特征（只作为溯源用的元信息保留）。粒径受工艺影响的程度不亚于受组成影响——同一组分比例，换一台微流控芯片、换一种搅拌方式，粒径可以差好几倍。当前特征几乎不含工艺信号，模型很可能无意中把"这篇论文/这个实验室"当成了预测粒径的捷径（同一实验室的工艺习惯是稳定的），而不是真正学到组成→粒径的因果关系。这个问题不会在整体 R² 上显形，但换一个全新配方（比如圣草酚+全新脂质组合）时会表现为预测失灵。

**③ 没有不确定性量化。** 现在的输出是一个裸的 nm 数字，没有置信区间或预测区间。R²=0.43 意味着模型本身噪声不小，任何真实决策场景（学术组挑下一步实验配方，或药企做 go/no-go）都不会接受不带置信度的点估计。这是 M5 demo 目前最容易被内行一眼看穿"是玩具"的地方。

**④ 跨实验室/跨批次变异完全没建模。** 34+ 篇论文池化训练，没有对"实验室"或"测量设备"做任何结构化处理（哪怕只是一个 `lab_id` 特征）。同一名义配方在不同实验室复现，粒径本身就有系统性差异——这是纳米药物递送文献里公认的痛点。把这类变异和真实的组成效应混在一起训练，是这次建模方法论上最根本的效度问题，比"三个数据源领域不完全一致"更底层。

**⑤ 项目自带一份数据质量审计表，从未接入过 M2–M4 pipeline（本次验证时才发现）。** `quality_reporting.csv`（221 行，对应 PMC_IVR 原始 IVR 曲线）本身就是一份逐条的报告质量/偏倚风险审核表：32/221（14.5%）曲线图分辨率被标记"Poor"；53/221（24%）被原始审核者判定"曲线形状不像一条真实的释放曲线"；11/221（5%）重复次数不足或未展示平均值。这份表在 M2/M3/M4 任何一版文档里都没被提及，更没有 join 进 `merge_schema.py`。也就是说，M4 里 PMC_IVR 那 187 行训练/评估数据，很可能相当一部分本身就是原始整理者自己标注过"数字化质量存疑"的记录，却原样拿去训练评估了。这可能是 PMC_IVR 子集 R²=-0.32（比瞎猜均值还差）的部分成因——不是纯粹"化学体系跨域迁移失败"，还叠加了"训练/评估集混入了已知质量存疑数据"这层因素，目前两者没有分开。这是一个几乎零成本能修的问题：数据已经在手，只是没接进去。

**⑥ 冷链/储存稳定性完全在平台范围之外。** LNP 类产品最著名的商业化痛点之一就是储存稳定性（mRNA-LNP 疫苗的超低温冷链是最直观的例子）。五个 target 列里没有一个和"放置 X 天/月后粒径、包封率是否漂移"相关。这个平台未来如果要向药企/CMO 讲故事，这一块的缺失会是最先被问到的问题之一。

## 二、三方角色模拟

### 角色一：哥本哈根药物组博士后（黄酮类药物透皮实验）—— 学术界视角

"我们组现在做的是黄酮类小分子的离体猪耳/人皮 Franz 扩散池实验，你这个平台第一眼就有问题：你预测的是纳米颗粒粒径，但我需要的终点是渗透通量、稳态渗透系数 Kp、24 小时累积渗透量，以及最关键的——毛囊 vs 角质层 vs 活性表皮的分区比例（我们用差异化撕胶带法测这个）。粒径只是配方能不能做出来的门槛条件，不是药效相关终点，你这套 R² 再高也回答不了我真正要的问题。

第二，你的电离脂质特征全部是围绕内体逃逸机制设计的——MC3、ALC-0315、SM-102 这些脂质解决的是"核酸分子进细胞后怎么从内体里逃出来"的问题。我的圣草酚是个抗氧化黄酮小分子，不需要进细胞内体，它要做的是穿过角质层、最好富集在毛囊漏斗部/外根鞘（黑色素干细胞所在的位置）。这是两个完全不同的物理化学问题，你的整个特征空间是为另一个问题优化的。

第三，我甚至没看到圣草酚自己的 logP、pKa、水溶性这些基础理化数据被系统性纳入——这些参数对透皮渗透的影响，说实话比脂质纳米颗粒组成本身还大。最后，你有没有拿任何一版模型预测跟哪怕一次真实的 Franz 池实验做过对照？我们这个领域，没有离体皮肤验证闭环的计算工具，说服力基本为零。"

### 角色二：诺和诺德生物化学研究工程师（测试平台对 amycretin/zenagamtide 的适配性）—— 商业/大药企视角

"我们现在推进的是 amycretin（现在也叫 zenagamtide）——GLP-1/胰淀素双激动剂，同时在做口服和皮下两条线，2026 年初刚进 III 期。评估你这个平台对我们的价值，第一个问题是：你的电离脂质-内体逃逸特征体系对我们的口服制剂几乎不适用。口服多肽面对的是完全不同的屏障——胃酸/蛋白酶降解、肠上皮吸收——这更接近渗透促进剂（比如口服司美格鲁肽用的 SNAC）要解决的问题，不是脂质纳米颗粒帮 mRNA 逃出内体的问题。你需要先说清楚这个平台到底覆盖哪类给药屏障，不能笼统说"适用于制剂预测"。

第二，数据溯源。我们内部任何进入 IND 相关决策的数据都要有仪器型号、SOP、批次可追溯性。你这 1900 多行是从 30 多篇论文里挖出来的，测量方法、仪器都不统一——你们自己那份质量审核表都标注了四分之一的曲线"形状不像真实释放曲线"，这种数据我们内部 QA 不会放行进任何决策支持工具。这类工具在我们这里最多算假设生成，不能算决策支持，这两者在药企内部是完全不同的审批级别。

第三，是我方会关心、但你们可能没想到的：'Custom lipid'那三分之一未溯源的记录里，会不会混进了竞品的专利配方（通过学术论文间接泄露的）？这对我们是尽职调查层面的风险，不只是数据质量问题。最后，微流控台架数据（Luciani 那 570 行）到我们连续化 GMP 量产的放大转化，文献里几乎没有先例支撑，这个 gap 你平台完全没触及。"

### 角色三：中国 CMO —— 工业/制造视角

"我从生产落地的角度看这个事。第一个卡点很直接：你这里大量 PEG 化脂质是'近似结构'，还有一部分脂质是'名字对不上结构'。我没法拿这些东西建生产批记录，我需要的是 CAS 号、供应商资质、GMP 级物料标准，一个带明确假设的理论 SMILES 我们 QA 不会接受。

第二，原料可获得性和成本。像 SM-102、ALC-0315 这类电离脂质专利保护很紧、供应链集中，如果未来要用这类脂质做圣草酚透皮产品，成本模型基本不成立——化妆品价格带扛不住疫苗级脂质的物料成本。如果是全新自研脂质，从合成工艺开发到分析方法验证起步就是几个月，很多脂质定制合成的最小订单量是公斤级，对早期研发是很重的负担。这其实是你 Track A/Track B 该不该共用同一套脂质库的问题，从成本角度答案已经很清楚——化妆品线更应该用大豆卵磷脂、氢化大豆卵磷脂这类早已过专利期、供应链成熟的磷脂，不该对标 mRNA 疫苗级配方。

第三，监管路径没定，我没法报价。头皮用的圣草酚脂质体产品，走妆字号普通化妆品、特殊化妆品，还是可能被认定为械字号/药品，这三条路径对应的 GMP 厂房资质、申报文件包完全不是一回事，报价和周期能差好几倍。

第四，分析方法一致性。你训练数据背后测粒径的仪器、方法本身就不统一，我们量产放大后自己也要做方法验证，你这份汇总数据没法直接告诉我'哪个测量方法是该对标的基准'。"

## 三、综合优化建议：M0–M5

| 阶段 | 主要来自 | 具体建议 |
|---|---|---|
| **M0 定义范围** | 三方共识 | 书面明确"这是配方可行性初筛工具，不是透皮功效预测工具，不是注册级 CMC 数据包"——从根上化解博士后和 NN 工程师最核心的质疑，也是申请材料里最省力的加分项 |
| **M1 数据采集** | 博士后 / CMO | 启动独立的透皮/毛囊渗透数据源（Franz 池文献挖矿），不假设 Track A 模型能直接迁移；新采集数据同步记录仪器型号/SOP，为质量分层预留字段 |
| **M2 schema 整合** | NN 工程师 / CMO | 把 `quality_reporting.csv` 这类质量标记系统化接入全部来源（不只 PMC_IVR），作为过滤或特征；为候选 payload 分子（圣草酚等）补一版独立理化表征字段（logP/pKa/溶解度） |
| **M3 特征工程** | 三方共识 | 结构化解析 LNP_Atlas 的 `synthesis_info` 工艺文本，降低"来源当捷径特征"的风险；对 approximated/unresolved 行做敏感性分析，量化它们对预测的系统性影响 |
| **M4 建模** | 三方共识 | 加不确定性量化（分位数回归或 conformal prediction）；把 `source_dataset`/lab 作为显式对照特征做消融实验，量化"记住来源"占了多少表现；PMC_IVR 单独建 source-aware 子模型，或明确标注当前不适用该场景 |
| **M5 demo/部署** | 三方共识 | 预测结果旁标注置信区间，以及输入结构的 resolved/approximated/unresolved 状态；遇到平台没见过的全新脂质结构时给低置信度警告，而不是直接吐一个数字 |

---

*核心结论：R²=-0.32 的 PMC_IVR 子集，很可能不是单纯的"化学体系跨域失败"，还叠加了本文档①⑤两条新发现——单一终点建模掩盖真实配方成功定义、以及训练数据里混入了已知质量存疑的记录。这两条都可以在不引入新数据源的前提下，用手头已有的数据修复，是当前性价比最高的下一步。*
