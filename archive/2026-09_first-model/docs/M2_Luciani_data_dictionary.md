## 一、和 LNP Atlas 的关键差异（先说清楚，别拿混了）

这不是"LNP"（没有电离脂质），是**经典脂质体**——只有三种组分：磷脂（Lipid）、胆固醇（CHOL %）、PEG化脂质（DSPE-PEG %），比 LNP Atlas 的四组分（电离/PEG/固醇/辅助脂质）少一种。这份数据完全不涉及"装了什么药"（没有 target_type、没有 encapsulation efficiency），只回答"这个配方+这个微流控工艺条件，能做出多大、多均匀的空脂质体"。它是**实验设计数据**（5 种磷脂 × 多组配比 × 多组流速条件，systematic screening），不是像 LNP Atlas 那样从几十篇论文里各种拼凑来的文献数据——所以极其干净、没有缺失值、没有编码问题、比例都精确加总等于 100%。

## 二、逐列字典（核心列，RDKit 描述符列略——跟 M3 会用的同一套，不重复解释）

| 列名 | 含义 | 格式/单位 | 备注 |
|---|---|---|---|
| `Lipid` | 主磷脂种类 | 分类，5 种：HSPC/DPPC/DMPC/DOPC/POPC，各 114 行，完全均衡 | 是脂质体膜的"骨架"成分 |
| `Lipid n%` | 主磷脂摩尔占比 | % | 与 CHOL%、DSPE-PEG% 三者相加恒等于 100（570 行全部验证通过） |
| `CHOL %` | 胆固醇占比 | % | 范围 0–40% |
| `DSPE-PEG %` | PEG化脂质占比 | % | 范围 0–5% |
| `CHIP` | 微流控芯片/设备类型 | 分类，1 或 2 | 对应论文里两台不同设备（Latina 实验室 vs Rome 实验室，或同类设备的两个批次） |
| `FRR` | Flow Rate Ratio | 数值 | 验证公式：**FRR = Org FR / TFR**（有机相流速占总流速的比例），不是有机相:水相的比值，命名容易让人会错意 |
| `Org FR` / `Aq FR` | 有机相/水相流速 | mL/min | `Org FR + Aq FR = TFR` 恒成立 |
| `TFR` | 总流速 | mL/min | 本数据集里**恒定为 12**，说明这批实验没有变动总流速，只变了 FRR 和配方 |
| `Size` | 粒径 | nm | ⚠️ 见下方"踩坑"第 1 条，有严重异常值 |
| `PDI` | 多分散指数 | 数值，理论范围 0–1 | ⚠️ 同上，有超出物理意义的异常值（最大到 65.6） |
| `Population` | 粒径分布峰数 | 1 或 2 | 1=单峰（均匀），2=双峰（不均匀，通常意味着形成质量差） |
| `Chain length 1/2`、`Unsatturation chain 1/2` | 主磷脂两条脂肪酸链的碳链长度/不饱和键数 | 整数 | 从 SMILES 解析出的结构特征，M3 会用到的那类信息这里已经提前给了 |
| `SMILES` | 主磷脂结构式 | 文本 | 只有 5 个不同值，对应 5 种磷脂 |
| 后面 208 列 | RDKit 分子描述符 | 数值 | 已经预计算好了（MolWt、LogP、TPSA 等一整套），等于帮你把 M3 对这批磷脂的特征化工作做完了 |

## 三、踩坑记录

1. **Size 和 PDI 里有物理上不合理的异常值**：Size 最大到 1,130,624 nm（超过 1 毫米，不可能是真实"纳米颗粒"），PDI 最大到 65.6（PDI 理论上限是 1，超过 1 就没有物理意义）。这些不是缺失值（缺失值这份数据里完全没有），而是**配方失败/聚沉/仪器测不出正常读数**时被记成了一个夸张数字，不是 NaN。全部 570 行里有 143 行（25%）落在这种"异常区间"（Size>1000nm 或 PDI>1）。**用这份数据训练模型前，必须先按合理物理范围（比如 Size<1000nm 且 PDI≤1）过滤掉这批"失败配方"，否则会把回归结果拉得很离谱。**
2. 这批"异常值"不是集中在某一个 CHIP 上（两个芯片类型里失败比例差不多），说明是配方本身（磷脂种类+配比+流速组合）导致的不稳定，不是设备问题——这其实是个有意思的信号，说明"是否能形成稳定脂质体"本身就是一个值得单独建模的问题（原作者也确实在 `03_Liposome_Formation` 那几个脚本里专门做了这个分类任务）。
3. `FRR` 的定义容易理解错——不是常见的"有机相:水相"比值，是"有机相占总流速的比例"，用之前最好按公式重新算一遍确认，不要直接信列名。

## 四、和 LNP Atlas 对齐时要注意

- 这份数据没有 target_type/载荷概念（纯空脂质体研究），LNP Atlas 有。合并时如果要统一 schema，这份数据的载荷相关字段应该留空/标记"N/A（未测试载药）"，不能瞎填。
- 组分只有三种（磷脂/胆固醇/PEG脂质），没有"电离脂质"和"辅助脂质"的区分——LNP Atlas 的 helper_lipid 概念在这里其实近似对应"主磷脂"本身的角色（很多经典磷脂如 DOPE/DSPC 在 LNP Atlas 里被归为 helper_lipid，但在这份数据里磷脂是主角）。统一 schema 时要想清楚这两个"lipid 角色"怎么对应，不能直接拿列名对列名。
- Population、CHIP、FRR/Org FR/Aq FR/TFR 这些工艺参数是 LNP Atlas 里 `synthesis_info` 文本字段里才有的信息（LNP Atlas 是塞成一整块文本，这份数据是拆好的独立列）——统一后 LNP Atlas 那边的 synthesis_info 也得拆开才能对齐，之前 M1 已经记过这个坑。
