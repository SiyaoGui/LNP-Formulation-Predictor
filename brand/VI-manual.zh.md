## 0. 一句话原则

LipidLens 看起来应该像一本认真编写的教科书，或一台做工精密的实验室仪器：平静、可信、讲得清楚。不兴奋，不未来感，不制造悬念。

理由：
- 第 2 节要求整体气质是「可信、平静、已被验证」。
- 第 3 节要求丹麦投资人的第一反应是「做精密科学仪器的严肃公司」。

两者在「教学挂图、仪器面板」这个交集上重合，所以这里的每条规则都从这个交集出发。

### 一个必须说清楚的张力

课本气质的关键词是「已被验证」。而 LipidLens 现在没有独立实验室验证。

所以这套视觉只借用「讲清楚」和「平静」，不借用「已验证」。凡是涉及能力和结果的地方，都必须按第 6 节的证据规则标注状态。视觉越可信，文字就越要诚实，否则这套风格会变成误导。

## 1. 标志系统

文件在 `logo/` 里，全部是 SVG，字标已经转成轮廓，不依赖本机字体。

### 来源（v1.1 更新）

标志**沿用 Skylab 申请时使用的 logo**（由一个 HTML 生成器导出），图形几何、字标、颜色完全不变。SVG 按生成器里的参数逐项重建，并和原生成器的渲染结果逐像素对照过，形状一致。

### 概念

- 外环加向心短线：一颗脂质颗粒的截面，外层脂质，尾链朝内。
- 右上角加粗的一段弧：被筛选出来的那一部分，也就是模型从很多配方里挑出来的那一个。

一个要注意的用词：Skylab 材料里把它叫作「脂质体截面」。严格说，脂质体是双层膜（见 `illustration/liposome.svg`），而这个图形是单层、尾朝内，更接近 lipid nanoparticle 的外层。路线是先做小分子（脂质体），再做大分子（lipid nanoparticle），最终覆盖两者，所以对外解释图形时建议说「a lipid particle in cross-section」，两种都不说错。

### 字标字体

字标是 Arimo Regular（Lipid）加 Arimo Bold（Lens），已转为轮廓。（v2.1 修改，原为 Poppins）

- 为什么改：提交给 Skylab 的 PNG 里，字母 i 的点是方的，字形是 Arial。原因是生成器写的是 Poppins，但导出时电脑没装 Poppins，浏览器退回到了 Arial（Light 没有对应字重，所以 Lipid 是 Arial Regular，Lens 是 Arial Bold）。评委看到的是 Arial 版，所以 VI 跟着提交版走。
- 为什么不直接用 Arial：Arial 归 Monotype 所有，随 Windows 附带不等于可以转曲做商标，这一点「未核实」，零预算下不冒这个险。Arimo 是 Steve Matteson 设计、与 Arial 字宽完全相同的开源字体，SIL OFL 1.1，已在 Google Fonts 官方仓库核实（[授权元数据](https://raw.githubusercontent.com/google/fonts/main/ofl/arimo/METADATA.pb)）。
- 和提交版的差别：逐像素叠图，图形重合度 99.2%，字标重合度 86.9%。差异来自 Arimo 的大写字母和 i 点比 Arial 低约 3%，字宽和字距一致。并排看分辨不出，叠在一起才看得到。
- Arimo 只存在于 logo 的轮廓里，网站、slide、文档的字体仍然是 Archivo。
- 原 Poppins 版生成脚本保留备查，不再对外使用。

| 项目 | 规定 |

- 不能换成标志色、白、墨之外的颜色。
- 不能放在照片或中等明度底色上（g400 到 g600）。
- 不能用别的字体重排字标。

### 2.7 数据可视化色板

| 序号 | Hex | 灰度 L* | 用途 |
|---|---|---|---|
| v1 | #1F3A2B 深绿 | 22 | 第一组数据，或「已验证 / 实测」 |

检验结果（用 Machado 2009 色盲模型计算）：
- 绿色盲下两两色差最小 44（ΔE）；红色盲下最小 40。一般认为 ΔE 大于 20 就容易分辨。
- 黑白打印下四个颜色的灰度依次是 22、50、66、75。v3 和 v4 只差 9，所以规则要求每个系列同时换标记形状和线型：圆 / 方 / 三角 / 菱形，实线 / 虚线 / 点划线 / 点线。这样黑白打印时靠形状也能分开。
- v3 和 v4 在纸色上的对比度低于 3:1（分别是 2.5:1 和 1.9:1）。规则：这两色的数据点必须带 0.6px 墨色描边；不能单独作为细线使用；v4 只做参照组。

热图用单色相顺序色带（#F3F5EF 到 #1E3B2A，亮度单调变化），黑白打印仍然有序。需要正负对比时用青蓝到赭的发散色带。

## 3. 字体系统

| 用途 | 字体 | 授权 | 链接 |
|---|---|---|---|
| 拉丁字母：标题、正文、数字、图表 | Archivo（Omnibus-Type 设计，可变字体，字重 100 到 900，字宽 62 到 125） | SIL OFL 1.1，已核实 | [Google Fonts](https://fonts.google.com/specimen/Archivo) / [授权元数据](https://raw.githubusercontent.com/google/fonts/main/ofl/archivo/METADATA.pb) |
| 中文正文和标题 | 思源黑体 Noto Sans SC | SIL OFL 1.1，已核实 | [Google Fonts](https://fonts.google.com/specimen/Noto+Sans+SC) / [授权元数据](https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/METADATA.pb) |
| 中文封面大标题（只用在米白标题块里） | 思源宋体 Noto Serif SC | SIL OFL 1.1，已核实 | [Google Fonts](https://fonts.google.com/specimen/Noto+Serif+SC) / [授权元数据](https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifsc/METADATA.pb) |

OFL 1.1 允许免费商用，可以嵌入网站和文档，唯一的限制是不能单独出售字体文件（[授权全文](https://openfontlicense.org/open-font-license-official-text/)）。

### 为什么是 Archivo

- 它是一款怪诞体（grotesque），和瑞士、德国教学挂图以及 Braun 产品标签上的字是同一类，对应第 3 节。
- 字宽轴可以收窄，图表标签和仪器标注可以用窄体（wdth 85）节省空间，不用换字体。
- 有等宽数字（tnum）、带斜杠的零（zero）、上下标（sups / sinf），化学式和数据表都用得上。
- 支持丹麦语字母 æ ø å，已核实。
- 正文和界面没有用 Inter、Poppins、Montserrat。logo 字标用 Arimo，原因见第 1 节「字标字体」。

### 中英混排规则

1. 中文用思源黑体，英文和数字用 Archivo。CSS 写 `font-family: Archivo, "Noto Sans SC", sans-serif;`，英文字母自动落到 Archivo，汉字落到思源黑体。

## 6. 数据可视化系统（重点）

### 6.1 证据规则（强制执行）

| 等级 | 含义 | 点 | 线 | 区域 | 图例写法 |
|---|---|---|---|---|---|
| 已验证（VALIDATED） | 独立实验室测量，成功标准事先写好 | 深绿实心圆 | 实线 | 实色半透明 | 「Independent lab test」 |
| 内部（INTERNAL） | 我们自己的数据，或文献数据的回测 | 灰色实心方块，深色描边 | 实线 | 实色半透明 | 「Internal back-test」或「Measured, internal」 |
| 预测（PREDICTED） | 模型输出、模拟 | 青蓝空心圆 | 虚线 | 斜线填充，点线边界 | 「Predicted」 |
| 示意（ILLUSTRATIVE） | 为解释而编的数字 | 以上任意一种 | | | 图的标题上方必须有方框标签「ILLUSTRATIVE DATA, NOT RESULTS」 |

规则：
1. 实心等于测到的，空心或斜线等于没测到的。这一条在全公司所有材料里只有这一种含义，不能挪作他用。
2. 一张图里出现预测值，图例里必须出现「Predicted」。
3. 当前阶段没有任何「已验证」数据。图里如果要留位置，图例写「Independent lab test: none yet」，不画点。
4. 示意数据的标签不能删、不能缩小、不能放到图外的注释里。
5. 预测值的不确定度区间必须画出来，没有区间的预测值不能单独展示。
6. 不能用颜色单独区分证据等级，因为黑白打印和色盲用户会看不出来。等级靠填充方式区分。

### 6.2 统一样式

- 白纸底（paper），只保留水平网格线（n200），去掉上和右的轴线。
- 标题左对齐、字重 600；轴标签写清单位，例如「Size (nm)」。
- 每个系列同时用颜色、标记形状、线型三重区分。
- 不用 3D、不用渐变填充、不用阴影、不用饼图。理由：教学挂图和 Scientific American 的图表都是平面的（第 3 节）。

### 必须写在图上的三句话

每张图解都要有：
- 「Schematic. Not to scale.」
- 尺度信息（例如「about 4 to 5 nm」）
- 凡是涉及 LipidLens 自己的部分（模块、模型），一律标「concept」或「in development」

## 8. 硬件呈现规则

改装模块目前还没有造出来。下面的规则从第一张原型照片就开始执行，现在先用于渲染图和示意图。

理由：硬件图是投资人判断「这是不是真东西」的主要依据，所以它最容易让人误以为产品已经存在。这一节的重点是：拍得像精密仪器，同时诚实。

### 8.1 标准机位（`hardware/01_camera_positions.svg`）

每个硬件版本都拍同一组四张，方便前后对比：

| 编号 | 机位 | 参数 | 用途 |
|---|---|---|---|
| 1 | 主图，3/4 视角 | 水平偏 45°，俯 30°，等效 50mm 焦距 | 网站首屏、slide 封面 |
| 2 | 正视 | 平视，与模块同高，尽量消除透视 | 技术页、尺寸说明 |
| 3 | 顶视 | 正上方垂直向下 | 接口和布局说明 |
| 4 | 细节 | 传感窗口或接口的特写 | 证据页 |

理由：固定机位像仪器目录，每一版都可比；不用夸张的低角度和广角，那是消费电子的拍法。

### 8.2 布光和背景（`hardware/02_lighting.svg`）

- **主光**：一个大的柔光源，放在左上 45°。和科学插图的受光方向一致，图和照片在同一页时光线统一。
- **补光**：右侧一块白色泡沫板。
- **背景**：纸白或浅绿 g100，一张无缝背景纸。
- **零预算做法**：靠窗的自然光，加一块白色泡沫板。
- **不用**：彩色滤光片、轮廓光、发光效果、黑底加聚光灯。

理由：教学挂图和 Braun 产品照都是平光、浅底；暗底加聚光是「发布会」气质，和第 4 节禁区里的暗底霓虹同类。

### 8.3 渲染

- 免费工具：Blender。材质用哑光，避免镜面反射和景深虚化过度。
- 颜色：模块外壳用品牌绿 g700 或中性灰 n300；不用发光指示灯效果，指示灯用 g100 的实色块表示。
- 构图：渲染图必须和真实芯片或混合设备同框，让人知道它装在哪里、有多大。

### 8.4 标注（`hardware/03_labels.svg`）

每一张硬件图左上角都放米白标签：

| 情况 | 标签 |
|---|---|
| 实拍原型 | `PROTOTYPE, [月份 年份]` |
| 渲染图 | `RENDER, CONCEPT` |
| 示意图 | `SCHEMATIC` |

另外两条：
- 画面里必须有比例尺（例如「10 cm」）或已知大小的物体（芯片）。
- 没有标签的硬件图不能用。

理由：防止任何人把渲染图当成已有产品，对应委托书「不得暗示已上市」。

### 8.5 硬件文案

- 只描述它做什么、装在哪里，不写性能数字，除非有测量数据。
- 不写「plug and play」「works with any mixer」这类还没验证的说法。可以写：「designed to fit existing microfluidic mixers」，并标明是设计目标。

## 9. 动效（Motion）

文件在 `motion/` 里。每个动效有一个可以直接播放的 HTML，以及一张最终帧的静态 SVG（`*_still.svg`），静帧可以直接放进 slide 和 PDF。

### 9.1 原则：动效像一张图在自己画出来

| 允许 | 禁止 |
|---|---|
| 线条描出来（stroke 绘制） | 飞入、弹跳、回弹、抖动 |
| 元素从附近移动到它该在的位置，然后停住 | 旋转进场、3D 翻转、视差滚动 |
| 淡入 | 粒子、光晕、闪烁、循环呼吸 |
| 区间带从中线展开 | 背景视频、自动播放的长动画 |
| 数值宽度平滑变化（选择性演示） | 和内容无关的装饰性动效 |

### 9.2 参数

| 参数 | 值 |
|---|---|
| 短（状态变化、指示灯） | 200ms |
| 中（单个元素落位） | 600ms |
| 长（绘线、移动进颗粒） | 1200ms |
| 一段完整动效 | 不超过 4 秒，播完停在最终帧，不循环（选择性演示每 4.2 秒切换一次，用户点击后停止自动切换） |
| 落位缓动 | `cubic-bezier(0.2, 0, 0, 1)`：快进慢停，像笔画收尾 |
| 绘线缓动 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 退出缓动 | `cubic-bezier(0.4, 0, 1, 1)` |
| 同时运动的元素 | 最多 3 个，用错开（stagger）实现顺序感 |
| 触发 | 滚动到画面 40% 可见时播放一次，可手动重播 |

### 9.3 什么时候完全不要动效

- 用户系统设置了「减少动态效果」（`prefers-reduced-motion: reduce`）：全部关闭，直接显示最终帧。
- 正文、表格、按钮、导航：永远不动。
- Slide 和 PDF：只用静帧。
- 同一屏已经有一个动效在播：不再启动第二个。

### 9.4 五个动效

| 文件 | 内容 | 时长 |
|---|---|---|
| `a1` | 磷脂自组装成双分子层：12 个磷脂从散乱位置依次落位，头朝外、尾相对 | 约 3.0 秒 |
| `a2` | 药物被包载：药物分子移进颗粒内核，外圈的缺口闭合 | 约 2.1 秒 |
| `a3` | 选择性（核心概念）：同一个药物，切换目标膜 A / B 时，膜的脂质组成条和推荐配方条一起变化。可以点按钮切换，也会自动切换 | 每次 0.6 秒 |
| `a4` | 硬件模块从上方落到芯片出口，指示灯亮，闭环虚线已就位 | 约 1.8 秒 |
| `a5` | 数据：对角线描出，8 个预测点依次落位，正负 10% 区间展开 | 约 3.2 秒 |

### 9.5 技术实现

- SVG 加 CSS 关键帧，加不到 60 行原生 JavaScript，不依赖任何库。
- 每个动效 HTML 文件在 8 到 55 KB 之间（不含网络加载的字体），最大的是包载动效，因为颗粒由 30 个脂质分子组成。
- 默认状态就是最终帧。动画只在加上 `.play` 类、并且用户没有关闭动态效果时才运行。所以关闭动效、或 JavaScript 加载失败时，画面依然完整可读。

### 9.6 诚信约束

- `a3` 的比例是占位数字，图上写明「Illustrative. Ratios are placeholders, not model output.」
- `a5` 图上有「ILLUSTRATIVE DATA」方框和「No independent lab data yet」。故意让两个点落在区间外，避免暗示模型很准。
- `a4` 写明「Concept. The module is in development and not a product.」

## 10. 明确不要做的事

1. 不用蓝紫渐变、发光分子、磨砂玻璃、暗底霓虹。
2. 不用节点连线式的「AI 大脑」、神经网络图形。
3. 不用六边形分子网格、DNA 双螺旋做装饰。
4. 不用粒子效果、光晕、镜头光斑。
5. 不用 AI 图像生成器的图片，也不用白大褂试管类的图库照片。
6. 不写 innovation、revolutionizing、cutting-edge、game-changing、breakthrough。
7. 不复制、临摹或在构图上接近人教版课本封面，不使用其书名、出版社标识和插图。
8. 不把预测值画成实心点，不删「ILLUSTRATIVE」标签。
9. 不写「validated」「proven」「clinically」「approved」，除非有对应的独立证据。
10. 不把科学图解色用作品牌色，不在一个界面里同时用超过三种品牌色。
11. 不用渐变色块、不用大圆角（大于 8px）、不用阴影卡片。
12. 不把深色版用作网站的整体底色。
13. 不用没有标签的硬件图；不用暗底聚光、彩色滤光片拍硬件。
14. 不调换、拉伸、旋转、重新着色 logo（见 `logo/misuse/`）。
