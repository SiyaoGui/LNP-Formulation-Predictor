# 大分子子集与跨子集对比（副产品，2026-10-20）

**一句话结论：大分子子集上所有模型都比常数基线更差，两个子集都没有得到可用的模型。**

这是作为副产品顺带跑的，不是独立的研究轮次。价值在三点：验证了「换子集只改一行配置」确实做到了；给出跨子集对比的同口径数字；暴露了一个在第一轮协议里已经预判到的结构性问题。

---

## 〇、怎么复现

```bash
python3 scripts/build_features.py --config configs/largemol_baseline.yaml --tasks t1
python3 scripts/run_modeling.py   --config configs/largemol_baseline.yaml --out modeling/2026-10-20_largemol-sideproduct --tasks t1 --schemes S3
python3 scripts/compare_subsets.py --small modeling/2026-10-19_smallmol-baseline --large modeling/2026-10-20_largemol-sideproduct --out modeling/2026-10-20_largemol-sideproduct
```

`configs/largemol_baseline.yaml` 与小分子配置**只差两处**：`subset.name` 和输出目录。建模代码一行没改。这是任务第 9 节「子集可配置」要求的实际验证。

## 一、大分子子集的规模，以及协议预判到的退化

| 指标 | 大分子 | 小分子（第一轮） |
|---|---|---|
| T1 分析单元 | **322** | 73 |
| 论文 | **55** | 26 |
| 唯一「化合物」 | **5**（mRNA / siRNA / DNA / ASO / protein） | 15 |
| 特征缺失占比 | **66.7%** | 13.1% |

**分组键在这一侧退化了**，这正是协议 11.2 节在第一轮跑完之前就写下的预判：

- 按 payload 分组只剩 5 个分组，而且这 5 个是「类别」不是「结构」
- 核酸没有 SMILES，所以 payload 的描述符和 2048 位指纹**整块为空**，这就是 66.7% 缺失的来源
- **B1 Tanimoto 相似性基线在这一侧无法实现**（算不出分子相似度）
- **B3「只有分子特征」在这一侧不可计算**

所以跨子集对比只能用**按论文分组（S3）**这一口径，它是唯一在两边定义完全相同、分组数都够的划分。协议事先就是这么定的，本轮按此执行。

## 二、大分子 T1 结果（按论文分组，55 篇，5 个种子）

| 模型 | MAE（log10） | 跨种子 sd | R² | 对常数基线 |
|---|---|---|---|---|
| **B0 常数基线** | **0.1584** | 0.0024 | −0.078 | — |
| B1（退化，见下） | 0.1557 | 0.0018 | −0.037 | — |
| Ridge 完整特征 | 0.1680 | 0.0050 | −0.195 | **−0.0097，5/5 种子区间排除 0（更差）** |
| 随机森林 完整特征 | 0.1786 | 0.0075 | −0.389 | −0.0202，5/5（更差） |
| 梯度提升树 完整特征 | 0.1875 | 0.0113 | −0.452 | −0.0291，2/5（更差） |
| B2 Ridge（无分子特征） | 0.1680 | 0.0050 | −0.195 | 与完整特征**完全相同** |
| B2 梯度提升树（无分子特征） | 0.1875 | 0.0113 | −0.452 | 与完整特征**完全相同** |
| B3（只有分子特征） | 退化，见下 | — | — | — |

**没有任何模型打败常数基线，而且三个模型都显著更差**（Ridge 和随机森林的 5 个种子区间全部排在 0 的负侧）。

### 两处必须说明的退化

**1. B2 与完整特征的数字一字不差。** 这不是巧合：payload 的分子特征整块为空，折内筛选把它们全部丢掉，所以「完整特征」实际上就等于「配方加工艺」。这反过来证实了大分子侧根本没有分子信息可用。

**2. B3「只有分子特征」是两种不同形式的退化。**

- 梯度提升树：剔掉空列后一个特征都不剩，拟合失败，按既定规则降级成常数预测，**降级折数 25**（记录在 `metrics.json` 里）
- Ridge：没有报错，但填充器处理全空列后只剩下常量的缺失指示列，Ridge 在常量特征上输出的就是训练集均值，**数值上与常数基线每个种子都一模一样**

第二种退化是沉默的，光看 MAE 会以为它是一个"表现等于基线"的模型。`scripts/compare_subsets.py` 原来就被它骗过，把它选成了大分子侧「最好的模型」，给出一个假的 skill score = 0。本轮已修：对比脚本现在同时按「降级折数大于 0」和「每个种子的指标与常数基线数值相同」两个判据排除退化模型，并把被排除的模型名写进 `comparison.json`。

## 三、跨子集对比（口径：按论文分组）

完整结果在 `comparison.json`。

| | 小分子 | 大分子 |
|---|---|---|
| 分析单元 | 73 | 322 |
| 常数基线 MAE | 0.2430 | 0.1584 |
| 最好的非退化模型 | 随机森林（完整特征）0.2262 | Ridge（完整特征）0.1680 |
| **相对常数基线的 skill score** | **+0.069** | **−0.061** |
| 相对相似性基线的 skill score | +0.173 | −0.079（B1 在此侧退化，不可解读） |

**怎么读这张表：**

- **不能比 MAE 的绝对值。** 大分子的 0.1584 看起来比小分子的 0.2430 小，但那只说明大分子子集的粒径分布更集中（现代 LNP 工艺更标准化），不说明模型更好。
- **要比的是相对各自基线的提升。** 小分子 +6.9%（点估计为正，但第一轮已证明其置信区间跨过 0，不显著），大分子 −6.1%（比基线更差）。
- **两边的结论是一致的：按论文分组时，两个子集都得不到可用的模型。**

### 必须一起声明的混杂（协议 11.1 第 5 条）

小分子子集 = PMC_IVR = 经典脂质体 = 无可离子化脂质；大分子子集 = LNP_Atlas = 现代 LNP = 有可离子化脂质。**子集标签、数据来源、脂质体类型三者完全共线。**

所以上表的差异**只能表述为「这两个数据集之间的差异」，不能归因为「小分子 vs 大分子」**。这句话在 `compare_subsets.py` 里被写成常量，每次对比都会打印出来，防止省略。

## 五、对整体判断的影响

这个副产品**不改变**前面两轮的结论，但加强了其中一条：

**论文之间的不可比性，是跨越子集、跨越目标变量的共同瓶颈。**

三组证据现在指向同一件事：

| 数据 | 目标 | 按论文分组后的结果 |
|---|---|---|
| 小分子（73 单元） | 粒径 | 优势从 +0.061 掉到 +0.003 |
| 大分子（322 单元） | 粒径 | 所有模型比常数基线更差 |
| LNP Atlas（370 单元） | 包封率 | 优势从 +4.99pp 掉到 +0.01pp |

样本量从 73 涨到 370 没有改变这个结论，换目标变量也没有。**这进一步支持 `docs/data-spec-ee.md` 的核心主张：继续堆文献数据解决不了问题，要自己在固定方案下采数据。**
